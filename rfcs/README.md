# RFCs

Design proposals for substantial changes to wesc. Each RFC is one Markdown file,
numbered and named (`NNNN-short-title.md`), following the section layout of
[RFC 0001](./0001-lazy-components.md): Summary, Motivation, Guide-level and
Reference-level explanation, Drawbacks, Rationale & alternatives, Prior art,
Unresolved questions, Future possibilities.

Keep one RFC per cohesive feature; spin a clearly separable extension into its
own follow-up RFC rather than growing an existing one.
